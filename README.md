# 🕉️ Mahadev & Parvati - Divine Particle Formation

A mesmerizing particle animation that forms the divine image of Mahadev and Parvati from scattered particles.

## ✨ Features

- 🌌 Universe background with twinkling stars
- 💫 Particle-based image formation
- ⚡ Fast and smooth animation
- 🎨 Divine glow effects
- 📱 Fully responsive
- 🕉️ Om symbol with pulsing animation
- 📿 Sacred mantras

## 🚀 Live Demo

Visit: [https://rishu160.github.io/mahadev/](https://rishu160.github.io/mahadev/)

## 🛠️ Technologies Used

- HTML5 Canvas
- Vanilla JavaScript
- CSS3 Animations
- Particle System

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/rishu160/mahadev.git
```

2. Open `index.html` in your browser
